# 诗藏本体论 ShiCang Ontology v1.0

参照佛藏本体论 (https://yejinlei.github.io/Buddhist/) 七层架构，基于殆知阁（https://daizhige.org/）诗藏 776 部典籍构建的中国古典诗歌领域知识本体。

- 在线访问：https://yejinlei.github.io/ShiCang/
- 本休文件：`诗藏本体论.owl`（W3C OWL/XML 标准，可导入 Protégé）

## 本体结构

| 维度 | 规模 |
|------|------|
| 顶层核心类 | 10 个（人物/作品/形式/内容/时代/地域/流派/典籍/诗学概念/事件） |
| 子类层级 | 75 类 |
| 对象属性 | 27 个 |
| 数据属性 | 16 个 |
| 预定义实例 | 85 个 |

## 七层架构

- L0 元模型层
- L1 诗理本体层（诗言志/诗缘情/诗达义/意境/风骨/神韵/性灵/格调/境界）
- L2 范畴层（体裁/格律/修辞/意象/风格/情感/题材）
- L3 流派体系层
- L4 文本载体层（诗藏 776 部）
- L5 人物传承层
- L6 文化外延层
